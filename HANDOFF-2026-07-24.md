## Environment notes for the new login

- **DB**: local dev uses the production Neon Postgres (`.env.local`). Schema
  changes: edit `prisma/schema.prisma`, run
  `set -a && . ./.env.local && set +a && npx prisma db push`, restart the dev
  server (stale Prisma client crashes at runtime).
- **Dev server**: `npm run dev` → port 3002. Local admin login:
  `/admin/dev-login?next=/admin/...` (inert in production).
- **Uploads**: Vercel Blob via OIDC on prod. Local uploads need
  `BLOB_READ_WRITE_TOKEN` pasted into `.env.local` from the Vercel dashboard
  (it's a "sensitive" env var — CLI pull returns it empty). A backup of
  `.env.local` from before edits exists as `.env.local.bak-*` (not committed).
- **Check the Vercel Storage tab** for a stray blob store named
  `ibf-training-2` (created accidentally while debugging, may need deleting;
  `ibf-training` was already removed). The real store predates this session.
- Docs uploaded to the Training document library **before July 23** have no
  extracted text — re-add them so they inform generation.
